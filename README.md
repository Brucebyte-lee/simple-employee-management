Employee Management System

A simple Employee Management System built with Python and MySQL.

Features

- Add employees
- View employees
- Update employee information
- Delete employees
- Search for employees
- Store employee information in a MySQL database

Technologies Used

- Python
- MySQL
- MySQL Connector/Python
- python-dotenv

Project Purpose
Project Purpose

This project provides a simple digital solution for managing employee records in a real-world organizational environment. It allows users to add, view, update, delete, and search employee information efficiently while storing records in a MySQL database.

The system demonstrates how Python and database technologies can be used to solve everyday business information management needs, reduce reliance on manual record keeping, and make employee information easier to organize and access.

Key Features

- Add Employees — Register new employees and store their information.
- View Employees — Display employee records stored in the database.
- Update Employees — Modify existing employee information.
- Delete Employees — Remove employee records when necessary.
- Search Employees — Quickly find specific employees using their information.
- MySQL Database — Store and manage employee records in a structured relational database.
- Secure Credentials — Database credentials are managed using environment variables rather than being exposed in the source code.
Security

Database credentials are stored in a ".env" file and are excluded from GitHub using ".gitignore".
